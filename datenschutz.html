2. Hosting durch GitHub Pages

Diese statische Website ist zur Veröffentlichung über GitHub Pages vorbereitet. Bei entsprechendem Hosting werden die Inhalte technisch über GitHub bereitgestellt. GitHub gibt an, beim Aufruf einer GitHub-Pages-Seite insbesondere die IP-Adresse der Besuchenden aus Sicherheitsgründen zu protokollieren – unabhängig davon, ob sie bei GitHub angemeldet sind.

Beim Seitenaufruf können dabei technisch erforderliche Informationen wie IP-Adresse, Zeitpunkt und angeforderte Ressourcen verarbeitet werden. Die Verarbeitung erfolgt für die Bereitstellung, Sicherheit und Stabilität des Angebots auf Grundlage von Art. 6 Abs. 1 lit. f DSGVO (berechtigtes Interesse). Konkrete Speicherfristen und etwaige internationale Datenübermittlungen richten sich nach den technischen und datenschutzrechtlichen Rahmenbedingungen des Hosting-Anbieters.

GitHub: Informationen zu GitHub Pages · GitHub-Datenschutzhinweise.

3. Cookies, Tracking und externe Inhalte

Diese Website setzt im bereitgestellten Ausgangszustand keine eigenen Cookies, kein Web-Analytics, keine Werbetracker und keine eingebetteten Drittanbieter-Videos ein. Auch die Schriftarten und Bilder werden lokal aus den Website-Dateien geladen. Die Sprachauswahl wird nur innerhalb der URL (Parameter ?lang=en) und der aktuellen Seitenanzeige verwendet; es findet keine Speicherung im Browser mittels LocalStorage statt.

Das bloße Laden dieser Website bindet keine externen Schriften, Analyse-Dienste oder Social-Media-Widgets ein. Externe Websites werden erst beim Anklicken entsprechender Links aufgerufen. Die Behandlung von Daten durch diese externen Dienste bestimmt sich nach deren eigenen Datenschutzhinweisen.

Grundlage kann Art. 6 Abs. 1 lit. b DSGVO sein, soweit deine Anfrage einen Vertrag oder vorvertragliche Maßnahmen betrifft, andernfalls Art. 6 Abs. 1 lit. f DSGVO (berechtigtes Interesse an der Beantwortung von Anfragen).

Die Daten werden nur so lange aufbewahrt, wie dies für die Bearbeitung erforderlich ist beziehungsweise gesetzliche Aufbewahrungspflichten bestehen. Auf dieser Website gibt es derzeit kein Kontaktformular und keinen Newsletter.

Vor dem App-Release ist deshalb eine separate, konkrete App-Datenschutzerklärung zu erstellen beziehungsweise zu ergänzen. Sie muss den tatsächlich implementierten SDKs, Datenflüssen, Berechtigungen, Käufen und gegebenenfalls eingesetzten Werbediensten entsprechen. Diese Website-Erklärung ersetzt keine App-Privacy-Angaben in Google Play oder im Apple App Store.

2. Hosting with GitHub Pages

This static site is prepared for publication through GitHub Pages. If hosted there, the site is delivered by GitHub. According to GitHub, visitors' IP addresses are logged for security purposes, regardless of their GitHub sign-in status.

Technically necessary information such as IP addresses, timestamps and requested resources may be processed to deliver, secure and maintain the site. The legal basis is Art. 6(1)(f) GDPR (legitimate interest). Retention periods and potential international transfers depend on the hosting provider's technical and privacy practices.

GitHub: GitHub Pages documentation · GitHub privacy statement.

3. Cookies, tracking and external content

As delivered, this website uses no first-party cookies, analytics, advertising trackers or embedded third-party videos. Images and fonts are loaded locally. The selected language is reflected only in the URL (?lang=en) and the current page; LocalStorage is not used.

No external fonts, tracking services or social widgets are loaded automatically. External websites are opened only after a visitor clicks an outbound link, and those websites are governed by their own privacy notices.

Messages are retained only as necessary to handle the request or to meet legal retention obligations. The website currently provides no contact form and no newsletter.
